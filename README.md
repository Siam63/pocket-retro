# Pocket Retro storefront

A zero-backend static product catalog for R36S handhelds and accessories.

## Run locally
Open `index.html` directly, or run any static web server in this folder.

## Free hosting with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose the `main` branch and `/ (root)`, then Save.
6. GitHub will provide the public `github.io` URL.

## Edit products
Open `app.js` and edit the `products` array. Prices, descriptions and product cards update automatically.

## Before publishing
Replace "Pocket Retro" with your final store name if desired. Add your Instagram/Facebook profile links once you have them. Product imagery can also replace the generated colour swatches later without changing the site structure.
